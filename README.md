# Peachy Keen 🍑

A peach to smack, pull and oil up. Built with Three.js.

Live at https://florisveldhuizen.github.io/peachy-keen/

This repo is a copy. The source lives in `src/peachy-keen` of
[florisveldhuizen.github.io](https://github.com/FlorisVeldhuizen/florisveldhuizen.github.io).
Make changes there and run `scripts/sync-peachy-keen.sh` to update this repo.

## Run

```
yarn install
yarn dev
```
